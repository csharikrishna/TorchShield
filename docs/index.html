Engineered for High-Consequence AI

Standard PyTorch checkpointing leaves models vulnerable to pickle exploits, weight tampering, and supply-chain attacks. TorchVault provides defense-in-depth.

Authenticated Streaming AEAD

Encrypted with NIST SP 800-38D AES-256-GCM. 128-bit authentication tags verify every chunk in memory. Any modification or single-bit corruption fails closed immediately.

Zero-Pickle Architecture

Tensors are serialized via strict IEEE 754 binary buffers and canonical JSON. Completely immune to Python pickle arbitrary code execution (RCE) vulnerabilities.

Ed25519 Publisher Signatures

Cryptographic asymmetric signatures bind canonical RFC 8785 JSON manifests transitively to all model weights. Verify training provenance without sharing decryption keys.

0x00 - 0x28 (40 Bytes) Container Public Envelope
Magic: "AHCC\x00CK5" | Version: 0x05 | Salt: 32B
Unencrypted outer header. The 32-byte salt is an RFC 5869 public extraction parameter for HKDF-SHA256 domain-separated subkey generation.
0x29 - Offset (Variable) Streaming Chunk Envelopes (1..M)
AES-256-GCM / Monotonic Nonce
Tensors are partitioned into 4 MiB streaming chunks. Each chunk contains a 12-byte counter nonce (b"CHNK" + uint64_be), encrypted tensor payload, and a 16-byte Poly1305/GCM authentication tag. Zero collision risk ($P=0$).
Trailer Envelope Canonical Manifest & Ed25519 Signature
RFC 8785 JSON | Ed25519 (64B)
Encrypted canonical JSON cataloging tensor shapes, dtypes, AdamW momentum, RNG states, and training progress. Digitally signed with an Ed25519 publisher key, transitively binding every single weight parameter in the model.

Drop-in Integration in Minutes

Seamlessly integrates with vanilla PyTorch training loops and Hugging Face Trainer with zero code architectural changes.

train_secure_checkpoint.py 
import secrets
import torch
from ahcc import save_training_checkpoint, load_training_checkpoint, TrainingProgress

# 1. 256-bit symmetric key (or AWS KMS provider)
key = secrets.token_bytes(32)

# 2. Save complete state (model weights, AdamW momentum, learning rate, & RNG)
save_training_checkpoint(
    output_path="checkpoints/epoch_10.ahcc",
    key=key,
    model=model,
    optimizer=optimizer,
    progress=TrainingProgress(epoch=10, global_step=5000, loss=0.1425),
)

# 3. Resume in a fresh process with exact mathematical bitwise equivalence
progress = load_training_checkpoint(
    input_path="checkpoints/epoch_10.ahcc",
    key=key,
    model=fresh_model,
    optimizer=fresh_optimizer,
    device="cuda",
)
print(f"Resumed at step {progress.global_step}")
huggingface_secure_trainer.py 
import secrets
from transformers import Trainer, TrainingArguments
from ahcc import TorchVaultTrainerCallback

key = secrets.token_bytes(32)

# Attach callback to automatically save encrypted, pickle-free checkpoints
callback = TorchVaultTrainerCallback(
    key=key,
    vault_filename="torchvault_checkpoint.ahcc",
    remove_insecure_pickle=True,  # Purges unsafe optimizer.pt, scheduler.pt, rng_state.pth
)

trainer = Trainer(
    model=model,
    args=TrainingArguments(output_dir="./secure_ckpts", save_steps=500),
    train_dataset=train_dataset,
    callbacks=[callback],
)
trainer.train()
